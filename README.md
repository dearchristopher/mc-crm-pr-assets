# mc-crm-pr-assets

Auto-generated PR screenshots for [`dearchristopher/mc-crm`](https://github.com/dearchristopher/mc-crm).

These PNGs are referenced as `<img>` embeds in PRs opened by the **uxhunter** Claude Code agent.

## Naming convention

```
<pr-slug>-before_<branch>.png
<pr-slug>-after_<branch>.png
```

## Maintenance

Files older than ~90 days can be pruned without breaking anything that still matters
(open PRs link to specific commits in this repo and would re-render only if the file
is gone). Closed PR assets are safe to delete at any time.
